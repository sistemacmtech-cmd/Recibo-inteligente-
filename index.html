Termos e Privacidade

1. Aceitação e Objeto

Este aplicativo PWA "Recibo Inteligente" destina-se ao gerenciamento local e geração de recibos de viagens de táxi. Ao utilizar o aplicativo, o usuário concorda com o funcionamento e com as diretrizes descritas neste documento.

2. Banco de Dados Local e Offline

Todas as informações cadastradas (incluindo dados do motorista, senha de acesso local, dados bancários, valores e imagens/logomarcas) são salvas exclusivamente no banco de dados interno do navegador ou dispositivo do usuário (IndexedDB). Não há transmissão de dados pessoais para servidores externos não autorizados.

3. Responsabilidade sobre os Dados Emitidos

O motorista é integralmente responsável pela veracidade das informações digitadas nos recibos, bem como pelo correto preenchimento de seu CPF ou CNPJ e valores cobrados. O aplicativo fornece a ferramenta de emissão e compartilhamento via PDF, WhatsApp ou E-mail.

4. Direitos Autorais e Desenvolvimento

Este aplicativo foi desenvolvido por sistemacmtech@gmail.com. Todos os direitos de código-fonte, layout e arquitetura do software pertencem à sua criadora.

1. Privacidade e Coleta de Dados

Respeitamos rigorosamente a sua privacidade. Este aplicativo opera sob a premissa de Privacidade por Design (Privacy by Design). Nenhum dado do cliente ou do motorista é vendido ou compartilhado com terceiros.

2. Armazenamento Local no Dispositivo

O armazenamento é mantido no armazenamento local seguro (IndexedDB e LocalStorage) do seu próprio dispositivo móvel ou computador. Limpar o cache do seu navegador pode apagar os dados salvos caso não seja realizado um backup prévio.

3. Contato e Suporte

Para dúvidas, suporte técnico ou informações sobre o código e desenvolvimento do aplicativo, entre em contato diretamente com a criadora pelo e-mail: sistemacmtech@gmail.com.
